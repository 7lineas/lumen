Antes de empezar

Qué necesita

  • Windows 10 o Windows 11, de 64 bits.
  • Un videobeam o segundo monitor, conectado por HDMI si va a proyectar.
  • Internet solo para descargar el programa; el culto puede seguir sin red.

Con un solo monitor también abre: la ventana del versículo queda junto al panel, útil para ensayar.

En pocos pasos

Cómo instalarlo

  1. Descargue el instalador.
  2. Ábralo con doble clic.
  3. Si Windows muestra el aviso de abajo, siga esos tres clics. No desactive el antivirus.
  4. Elija la carpeta de instalación y termine el asistente.
  5. Abra Lumen desde el menú Inicio.
  6. Conecte el videobeam, pulse Windows + P y elija Extender. En Ajustes, seleccione la pantalla del proyector.

La versión portable no se instala: se guarda el archivo y se abre cuando haga falta. Sirve en un computador donde no se pueden instalar programas.

i

Un aviso de Windows

Windows protegió su PC

El programa todavía no tiene firma digital, así que Windows lo trata como de un editor desconocido. El aviso es esperable. Para continuar:

  1. En la ventana azul, pulse Más información.
  2. Pulse Ejecutar de todas formas.
  3. Siga el instalador con normalidad.

Si no aparece «Más información», pida a quien administra el computador que permita abrir este archivo. No hace falta desactivar SmartScreen para todo Windows.
